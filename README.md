# Solar Fly — Sryde Gaming

**Solar Fly** is a 2D space adventure game developed by Sryde Gaming.

## Project overview
Solar Fly is an arcade-style space adventure featuring planetary exploration, physics-based flying, hazards, collectibles, achievements, and multiple difficulty levels.

## Technology
- HTML5, CSS, and JavaScript game
- Android application using Kotlin and Android WebView
- Google Play Games Services
- Google AdMob
- Firebase integration

## Main files to understand
- `Solar_Fly.html` — Main game implementation, gameplay logic, interface, and related systems.
- `MainActivity.kt` — Android application and WebView integration.
- `AndroidManifest.xml` — Android app configuration and permissions.
- `strings.xml` — Android string resources and game service identifiers.
- `build.gradle` — Android build configuration and dependencies.
